## 第1章 通用内存分配器分析

### 1.1 malloc/new性能开销

#### 1.1.1 malloc的隐藏成本

```cpp
#include <cstdlib>
#include <chrono>
#include <iostream>

void benchmark_malloc() {
    const int iterations = 1000000;

    auto start = std::chrono::high_resolution_clock::now();

    for (int i = 0; i < iterations; i++) {
        void* ptr = malloc(64);  // 分配64字节
        free(ptr);
    }

    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::nanoseconds>(end - start);

    std::cout << "Average malloc/free time: "
              << duration.count() / iterations << " ns\n";
}
// 典型结果：80-200 ns per malloc/free
```

**malloc开销分解：**
```
malloc/free单次开销（x86-64）：
1. 函数调用开销：       ~5 ns
2. 找到合适的块：       ~20-50 ns  (遍历freelist/B-tree)
3. 分裂/合并块：        ~10-30 ns  (如需要)
4. 元数据维护：         ~10-20 ns  (size, prev/next指针)
5. 多线程同步：         ~20-100 ns (锁竞争)
6. 系统调用（偶尔）：   ~1000+ ns  (brk/mmap)
----------------------------------------
总计：                  ~80-200+ ns
```

#### 1.1.2 内存碎片问题

```cpp
// 演示外部碎片
void demonstrate_fragmentation() {
    std::vector<void*> pointers;

    // 分配100个小块
    for (int i = 0; i < 100; i++) {
        pointers.push_back(malloc(32));
    }

    // 释放奇数位置的块
    for (size_t i = 1; i < pointers.size(); i += 2) {
        free(pointers[i]);
        pointers[i] = nullptr;
    }

    // 现在内存布局：[占用][空闲][占用][空闲]...
    // 无法分配一个64字节的连续块！
    void* large = malloc(64);
    // 可能触发新的系统调用

    // 清理
    for (auto ptr : pointers) {
        if (ptr) free(ptr);
    }
    free(large);
}
```

**碎片类型：**
- **外部碎片**：空闲块太小无法满足请求
- **内部碎片**：分配的块大于请求大小

#### 1.1.3 Cache性能影响

```cpp
struct Node {
    int data;
    Node* next;
};

// 不好：malloc分配的节点在内存中分散
void bad_allocation() {
    Node* head = nullptr;
    for (int i = 0; i < 1000; i++) {
        Node* node = new Node{i, head};  // malloc调用
        head = node;
    }
    // 节点在内存中随机分布
    // 遍历链表：大量Cache miss
}

// 好：连续分配
void good_allocation() {
    Node* nodes = new Node[1000];  // 一次分配
    for (int i = 0; i < 999; i++) {
        nodes[i].data = i;
        nodes[i].next = &nodes[i+1];
    }
    nodes[999].next = nullptr;
    // 节点在内存中连续
    // 遍历链表：良好的Cache局部性
}
```

## 第2章 Arena Allocator（区域分配器）

### 2.1 基本原理

Arena分配器从大块内存中按顺序分配，释放时一次性回收全部内存。

**优点：**
- 分配极快（只需移动指针）
- 无碎片
- 批量释放效率高

**缺点：**
- 无法单独释放对象
- 需要一次性释放所有对象

### 2.2 简单实现

```cpp
class Arena {
private:
    char* buffer_;
    size_t size_;
    size_t offset_;

public:
    explicit Arena(size_t size = 4096)
        : size_(size), offset_(0) {
        buffer_ = new char[size];
    }

    ~Arena() {
        delete[] buffer_;
    }

    // 禁止拷贝
    Arena(const Arena&) = delete;
    Arena& operator=(const Arena&) = delete;

    // 分配n字节，alignment字节对齐
    void* allocate(size_t n, size_t alignment = 8) {
        // 计算对齐后的offset
        size_t aligned_offset = (offset_ + alignment - 1) & ~(alignment - 1);

        // 检查是否有足够空间
        if (aligned_offset + n > size_) {
            return nullptr;  // 或者扩展arena
        }

        void* ptr = buffer_ + aligned_offset;
        offset_ = aligned_offset + n;
        return ptr;
    }

    // 批量释放所有分配
    void reset() {
        offset_ = 0;
    }

    // 获取已使用大小
    size_t used() const { return offset_; }

    // 获取总大小
    size_t capacity() const { return size_; }
};

// 使用示例
void arena_example() {
    Arena arena(1024 * 1024);  // 1MB

    // 分配一些对象
    int* numbers = static_cast<int*>(arena.allocate(100 * sizeof(int)));
    char* text = static_cast<char*>(arena.allocate(256));

    // 使用对象...
    for (int i = 0; i < 100; i++) {
        numbers[i] = i;
    }

    // 一次性释放所有
    arena.reset();
}
```

**性能对比：**
```cpp
void benchmark_arena_vs_malloc() {

// 典型结果：50-100倍加速
```

### 2.3 高级Arena实现

#### 2.3.1 支持扩展的Arena

```cpp
class ExpandableArena {
private:
    struct Block {
        char* data;
        size_t size;
        size_t offset;
        Block* next;

        Block(size_t sz)
            : size(sz), offset(0), next(nullptr) {
            data = new char[size];
        }

        ~Block() {
            delete[] data;
        }
    };

    Block* current_block_;
    Block* first_block_;
    size_t block_size_;
    size_t total_allocated_;

public:
    explicit ExpandableArena(size_t initial_block_size = 4096)
        : block_size_(initial_block_size), total_allocated_(0) {
        current_block_ = new Block(block_size_);
        first_block_ = current_block_;
    }

    ~ExpandableArena() {
        Block* block = first_block_;
        while (block) {
            Block* next = block->next;
            delete block;
            block = next;
        }
    }

    void* allocate(size_t n, size_t alignment = 8) {
        // 对齐
        size_t aligned_offset = (current_block_->offset + alignment - 1)
                                & ~(alignment - 1);

        // 如果当前块空间不足
        if (aligned_offset + n > current_block_->size) {
            // 分配新块（使用指数增长）
            size_t new_block_size = std::max(block_size_ * 2, n + alignment);
            Block* new_block = new Block(new_block_size);
            current_block_->next = new_block;
            current_block_ = new_block;
            block_size_ = new_block_size;

            aligned_offset = 0;
        }

        void* ptr = current_block_->data + aligned_offset;
        current_block_->offset = aligned_offset + n;
        total_allocated_ += n;

        return ptr;
    }

    void reset() {
        // 重置所有块
        Block* block = first_block_;
        while (block) {
            block->offset = 0;
            block = block->next;
        }
        current_block_ = first_block_;
        total_allocated_ = 0;
    }

    size_t total_allocated() const { return total_allocated_; }
};
```

#### 2.3.2 LevelDB中的Arena实现

```cpp
// 参考LevelDB的Arena实现
class LevelDBStyleArena {
private:
    char* alloc_ptr_;
    size_t alloc_bytes_remaining_;

    std::vector<char*> blocks_;
    size_t memory_usage_;

    static constexpr size_t kBlockSize = 4096;

public:
    LevelDBStyleArena()
        : alloc_ptr_(nullptr),
          alloc_bytes_remaining_(0),
          memory_usage_(0) {}

    ~LevelDBStyleArena() {
        for (char* block : blocks_) {
            delete[] block;
        }
    }

    char* Allocate(size_t bytes) {
        // 大对象单独分配
        if (bytes > kBlockSize / 4) {
            return AllocateNewBlock(bytes);
        }

        // 当前块空间不足
        if (bytes > alloc_bytes_remaining_) {
            AllocateFallback(bytes);
        }

        char* result = alloc_ptr_;
        alloc_ptr_ += bytes;
        alloc_bytes_remaining_ -= bytes;
        return result;
    }

    char* AllocateAligned(size_t bytes) {
        const int align = (sizeof(void*) > 8) ? sizeof(void*) : 8;
        size_t current_mod = reinterpret_cast<uintptr_t>(alloc_ptr_) & (align - 1);
        size_t slop = (current_mod == 0 ? 0 : align - current_mod);
        size_t needed = bytes + slop;

        char* result;
        if (needed <= alloc_bytes_remaining_) {
            result = alloc_ptr_ + slop;
            alloc_ptr_ += needed;
            alloc_bytes_remaining_ -= needed;
        } else {
            result = AllocateFallback(bytes);
        }

        return result;
    }

    size_t MemoryUsage() const {
        return memory_usage_;
    }

private:
    char* AllocateNewBlock(size_t block_bytes) {
        char* result = new char[block_bytes];
        blocks_.push_back(result);
        memory_usage_ += block_bytes;
        return result;
    }

    char* AllocateFallback(size_t bytes) {
        if (bytes > kBlockSize / 4) {
            return AllocateNewBlock(bytes);
        }

        alloc_ptr_ = AllocateNewBlock(kBlockSize);
        alloc_bytes_remaining_ = kBlockSize;

        char* result = alloc_ptr_;
        alloc_ptr_ += bytes;
        alloc_bytes_remaining_ -= bytes;
        return result;
    }
};
```

**LevelDB Arena特点：**
- 小对象（< 1KB）从当前块分配
- 大对象（>= 1KB）单独分配块
- 内存对齐支持
- 跟踪总内存使用量

## 第3章 Object Pool（对象池）

### 3.1 基本原理

对象池预先分配一批固定大小的对象，重复使用避免频繁的malloc/free。

**优点：**
- 分配/释放极快（O(1)）
- 无碎片
- Cache友好（对象连续存储）

**缺点：**
- 需要预估对象数量
- 内存占用固定

### 3.2 简单实现

```cpp
template<typename T, size_t N>
class ObjectPool {
private:
    union Node {
        T object;
        Node* next;
    };

    Node pool_[N];
    Node* free_list_;
    size_t allocated_count_;

public:
    ObjectPool() : allocated_count_(0) {
        // 构建freelist
        for (size_t i = 0; i < N - 1; i++) {
            pool_[i].next = &pool_[i + 1];
        }
        pool_[N - 1].next = nullptr;
        free_list_ = &pool_[0];
    }

    ~ObjectPool() {
        // 确保所有对象已归还
        // assert(allocated_count_ == 0);
    }

    T* allocate() {
        if (!free_list_) {
            return nullptr;  // 池已耗尽
        }

        Node* node = free_list_;
        free_list_ = free_list_->next;
        allocated_count_++;

        // 返回对象指针（未初始化）
        return &node->object;
    }

    void deallocate(T* ptr) {
        if (!ptr) return;

        // 归还到freelist
        Node* node = reinterpret_cast<Node*>(ptr);
        node->next = free_list_;
        free_list_ = node;
        allocated_count_--;
    }

    // 带构造的分配
    template<typename... Args>
    T* construct(Args&&... args) {
        T* ptr = allocate();
        if (ptr) {
            new (ptr) T(std::forward<Args>(args)...);  // placement new
        }
        return ptr;
    }

    // 带析构的释放
    void destroy(T* ptr) {
        if (ptr) {
            ptr->~T();  // 显式调用析构函数
            deallocate(ptr);
        }
    }

    size_t capacity() const { return N; }
    size_t allocated() const { return allocated_count_; }
    size_t available() const { return N - allocated_count_; }
};

// 使用示例
struct GameObject {
    float x, y, z;
    int health;

    GameObject(float x_, float y_, float z_)
        : x(x_), y(y_), z(z_), health(100) {}
};

void object_pool_example() {
    ObjectPool<GameObject, 1000> pool;

    // 分配对象
    GameObject* obj1 = pool.construct(1.0f, 2.0f, 3.0f);
    GameObject* obj2 = pool.construct(4.0f, 5.0f, 6.0f);

    // 使用对象...
    obj1->health -= 10;

    // 归还对象
    pool.destroy(obj1);
    pool.destroy(obj2);

    // 再次分配（重用之前的内存）
    GameObject* obj3 = pool.construct(7.0f, 8.0f, 9.0f);
}
```

### 3.3 线程安全的对象池

```cpp
#include <mutex>
#include <atomic>

template<typename T, size_t N>
class ThreadSafeObjectPool {
private:
    union Node {
        T object;
        std::atomic<Node*> next;
    };

    Node pool_[N];
    std::atomic<Node*> free_list_;
    std::atomic<size_t> allocated_count_;

public:
    ThreadSafeObjectPool() : allocated_count_(0) {
        for (size_t i = 0; i < N - 1; i++) {
            pool_[i].next.store(&pool_[i + 1], std::memory_order_relaxed);
        }
        pool_[N - 1].next.store(nullptr, std::memory_order_relaxed);
        free_list_.store(&pool_[0], std::memory_order_release);
    }

    T* allocate() {
        Node* node = free_list_.load(std::memory_order_acquire);

        while (node) {
            Node* next = node->next.load(std::memory_order_acquire);
            // CAS操作
            if (free_list_.compare_exchange_weak(node, next,
                                                  std::memory_order_release,
                                                  std::memory_order_acquire)) {
                allocated_count_.fetch_add(1, std::memory_order_relaxed);
                return &node->object;
            }
            // CAS失败，重试
        }

        return nullptr;  // 池已耗尽
    }

    void deallocate(T* ptr) {
        if (!ptr) return;

        Node* node = reinterpret_cast<Node*>(ptr);
        Node* old_head = free_list_.load(std::memory_order_acquire);

        do {
            node->next.store(old_head, std::memory_order_release);
        } while (!free_list_.compare_exchange_weak(old_head, node,
                                                    std::memory_order_release,
                                                    std::memory_order_acquire));

        allocated_count_.fetch_sub(1, std::memory_order_relaxed);
    }

    size_t allocated() const {
        return allocated_count_.load(std::memory_order_relaxed);
    }
};
```

### 3.4 动态扩展的对象池

```cpp
template<typename T>
class DynamicObjectPool {
private:
    struct Block {
        char* data;
        size_t capacity;
        size_t used;
        Block* next;

        Block(size_t cap) : capacity(cap), used(0), next(nullptr) {
            data = new char[sizeof(T) * capacity];
        }

        ~Block() {
            delete[] data;
        }

        T* get(size_t index) {
            return reinterpret_cast<T*>(data + sizeof(T) * index);
        }
    };

    Block* first_block_;
    Block* current_block_;
    std::vector<T*> free_list_;
    size_t block_size_;

public:
    explicit DynamicObjectPool(size_t initial_block_size = 1024)
        : block_size_(initial_block_size) {
        first_block_ = new Block(block_size_);
        current_block_ = first_block_;
    }

    ~DynamicObjectPool() {
        Block* block = first_block_;
        while (block) {
            Block* next = block->next;
            delete block;
            block = next;
        }
    }

    T* allocate() {
        // 优先从freelist分配
        if (!free_list_.empty()) {
            T* ptr = free_list_.back();
            free_list_.pop_back();
            return ptr;
        }

        // 当前块已满，分配新块
        if (current_block_->used >= current_block_->capacity) {
            Block* new_block = new Block(block_size_ * 2);  // 指数增长
            current_block_->next = new_block;
            current_block_ = new_block;
            block_size_ *= 2;
        }

        T* ptr = current_block_->get(current_block_->used);
        current_block_->used++;
        return ptr;
    }

    void deallocate(T* ptr) {
        if (ptr) {
            free_list_.push_back(ptr);
        }
    }

    template<typename... Args>
    T* construct(Args&&... args) {
        T* ptr = allocate();
        new (ptr) T(std::forward<Args>(args)...);
        return ptr;
    }

    void destroy(T* ptr) {
        if (ptr) {
            ptr->~T();
            deallocate(ptr);
        }
    }
};
```

## 第4章 Stack Allocator（栈式分配器）

### 4.1 基本原理

Stack Allocator按栈的方式分配内存：后进先出（LIFO）。

**优点：**
- 分配极快（移动指针）
- 释放极快（回退指针）
- 无碎片

**缺点：**
- 必须按相反顺序释放
- 不支持随机释放

### 4.2 实现

```cpp
class StackAllocator {
private:
    char* buffer_;
    size_t size_;
    size_t offset_;

public:
    explicit StackAllocator(size_t size)
        : size_(size), offset_(0) {
        buffer_ = new char[size];
    }

    ~StackAllocator() {
        delete[] buffer_;
    }

    // 分配
    void* allocate(size_t n, size_t alignment = 8) {
        size_t aligned_offset = (offset_ + alignment - 1) & ~(alignment - 1);

        if (aligned_offset + n > size_) {
            return nullptr;
        }

        void* ptr = buffer_ + aligned_offset;
        offset_ = aligned_offset + n;
        return ptr;
    }

    // 获取当前栈顶标记
    size_t get_marker() const {
        return offset_;
    }

    // 回退到标记位置
    void free_to_marker(size_t marker) {
        offset_ = marker;
    }

    // 释放最近分配的n字节
    void deallocate(size_t n) {
        if (n <= offset_) {
            offset_ -= n;
        }
    }

    void reset() {
        offset_ = 0;
    }
};

// 使用示例
void stack_allocator_example() {
    StackAllocator stack(1024 * 1024);

    // 分配一些对象
    int* array1 = static_cast<int*>(stack.allocate(100 * sizeof(int)));
    float* array2 = static_cast<float*>(stack.allocate(200 * sizeof(float)));

    // 保存标记
    size_t marker = stack.get_marker();

    // 临时分配
    char* temp = static_cast<char*>(stack.allocate(1000));
    // 使用temp...

    // 释放临时分配
    stack.free_to_marker(marker);

    // 继续使用array1, array2...
}
```

### 4.3 双端栈分配器

```cpp
class DoubleEndedStackAllocator {
private:
    char* buffer_;
    size_t size_;
    size_t bottom_offset_;  // 从底部向上
    size_t top_offset_;     // 从顶部向下

public:
    explicit DoubleEndedStackAllocator(size_t size)
        : size_(size), bottom_offset_(0), top_offset_(size) {
        buffer_ = new char[size];
    }

    ~DoubleEndedStackAllocator() {
        delete[] buffer_;
    }

    // 从底部分配（长期对象）
    void* allocate_bottom(size_t n, size_t alignment = 8) {
        size_t aligned_offset = (bottom_offset_ + alignment - 1) & ~(alignment - 1);

        if (aligned_offset + n > top_offset_) {
            return nullptr;  // 两端相遇
        }

        void* ptr = buffer_ + aligned_offset;
        bottom_offset_ = aligned_offset + n;
        return ptr;
    }

    // 从顶部分配（临时对象）
    void* allocate_top(size_t n, size_t alignment = 8) {
        size_t aligned_offset = (top_offset_ - n) & ~(alignment - 1);

        if (aligned_offset < bottom_offset_) {
            return nullptr;  // 两端相遇
        }

        top_offset_ = aligned_offset;
        return buffer_ + top_offset_;
    }

    // 释放顶部到标记
    void free_top_to_marker(size_t marker) {
        top_offset_ = marker;
    }

    size_t get_top_marker() const { return top_offset_; }
    size_t get_bottom_marker() const { return bottom_offset_; }

    void reset() {
        bottom_offset_ = 0;
        top_offset_ = size_;
    }
};

// 应用：游戏引擎每帧分配
void game_frame_example() {
    DoubleEndedStackAllocator allocator(10 * 1024 * 1024);  // 10MB

    // 底部：持久对象（整个游戏生命周期）
    auto* renderer = allocator.allocate_bottom(sizeof(Renderer));
    auto* physics = allocator.allocate_bottom(sizeof(PhysicsEngine));

    while (game_running) {
        size_t frame_marker = allocator.get_top_marker();

        // 顶部：帧临时对象
        auto* frame_data = allocator.allocate_top(sizeof(FrameData));
        auto* particles = allocator.allocate_top(1000 * sizeof(Particle));

        // ... 游戏逻辑 ...

        // 帧结束：释放所有临时对象
        allocator.free_top_to_marker(frame_marker);
    }
}
```

### 5.3 Pool分配器用于STL

```cpp
template<typename T, size_t BlockSize = 4096>
class PoolAllocator {
private:
    struct Block {
        uint8_t data[BlockSize];
    };

    // 使用std::deque管理块
    std::deque<Block> blocks_;
    std::vector<T*> free_list_;
    size_t current_block_offset_;

public:
    using value_type = T;

    PoolAllocator() : current_block_offset_(0) {
        blocks_.emplace_back();
    }

    template<typename U>
    PoolAllocator(const PoolAllocator<U, BlockSize>&) {}

    T* allocate(std::size_t n) {
        if (n != 1) {
            // 不支持批量分配，回退到new
            return static_cast<T*>(::operator new(n * sizeof(T)));
        }

        // 从freelist分配
        if (!free_list_.empty()) {
            T* ptr = free_list_.back();
            free_list_.pop_back();
            return ptr;
        }

        // 从当前块分配
        if (current_block_offset_ + sizeof(T) > BlockSize) {
            blocks_.emplace_back();
            current_block_offset_ = 0;
        }

        T* ptr = reinterpret_cast<T*>(
            blocks_.back().data + current_block_offset_);
        current_block_offset_ += sizeof(T);

        return ptr;
    }

    void deallocate(T* ptr, std::size_t n) {
        if (n != 1) {
            ::operator delete(ptr);
            return;
        }

        free_list_.push_back(ptr);
    }

    template<typename U>
    struct rebind {
        using other = PoolAllocator<U, BlockSize>;
    };
};

// 使用示例
void stl_pool_example() {
    using List = std::list<int, PoolAllocator<int>>;
    List list;

    for (int i = 0; i < 10000; i++) {
        list.push_back(i);  // 从pool分配节点
    }

    // 删除元素不会释放内存，而是归还到pool
    list.clear();

    // 再次添加会重用之前的内存
    for (int i = 0; i < 10000; i++) {
        list.push_back(i);  // 极快！
    }
}
```

```cpp
// NUMA感知的内存池
class NUMAAllocator {
private:
    std::vector<void*> buffers_;
    std::vector<size_t> offsets_;
    size_t buffer_size_;

public:
    explicit NUMAAllocator(size_t buffer_size)
        : buffer_size_(buffer_size) {
        int num_nodes = numa_num_configured_nodes();
        buffers_.resize(num_nodes);
        offsets_.resize(num_nodes, 0);

        // 每个NUMA节点分配一个buffer
        for (int i = 0; i < num_nodes; i++) {
            buffers_[i] = numa_alloc_onnode(buffer_size, i);
        }
    }

    ~NUMAAllocator() {
        for (auto buf : buffers_) {
            numa_free(buf, buffer_size_);
        }
    }

    void* allocate(size_t size) {
        // 分配到当前CPU所在的NUMA节点
        int node = numa_node_of_cpu(sched_getcpu());

        if (offsets_[node] + size > buffer_size_) {
            return nullptr;  // 节点buffer已满
        }

        void* ptr = static_cast<char*>(buffers_[node]) + offsets_[node];
        offsets_[node] += size;
        return ptr;
    }
};
```

```cpp
#include <sys/mman.h>

// 分配huge pages内存
void* alloc_huge_pages(size_t size) {
    void* ptr = mmap(nullptr, size,
                     PROT_READ | PROT_WRITE,
                     MAP_PRIVATE | MAP_ANONYMOUS | MAP_HUGETLB,
                     -1, 0);

    if (ptr == MAP_FAILED) {
        return nullptr;
    }

    return ptr;
}

// 释放
void free_huge_pages(void* ptr, size_t size) {
    munmap(ptr, size);
}

// Transparent Huge Pages (THP)
void enable_thp_for_region(void* addr, size_t length) {
    // 提示内核使用THP
    madvise(addr, length, MADV_HUGEPAGE);
}

// 性能测试
void benchmark_huge_pages() {
    const size_t size = 1024 * 1024 * 1024;  // 1GB

    // 标准4KB页
    auto start = std::chrono::high_resolution_clock::now();
    void* normal_mem = mmap(nullptr, size,
                            PROT_READ | PROT_WRITE,
                            MAP_PRIVATE | MAP_ANONYMOUS,
                            -1, 0);
    // 随机访问测试...
    auto normal_time = std::chrono::high_resolution_clock::now() - start;
    munmap(normal_mem, size);

    // 2MB大页
    start = std::chrono::high_resolution_clock::now();
    void* huge_mem = alloc_huge_pages(size);
    // 随机访问测试...
    auto huge_time = std::chrono::high_resolution_clock::now() - start;
    free_huge_pages(huge_mem, size);

    std::cout << "Normal pages: " << normal_time.count() << " ns\n";
    std::cout << "Huge pages: " << huge_time.count() << " ns\n";
    std::cout << "Speedup: " << normal_time / huge_time << "x\n";
}
// 典型结果：10-30%性能提升（取决于访问模式）
```

**Huge Pages优势：**
- 减少TLB miss（页表缓存未命中）
- 减少页表层级遍历
- 适合大内存、随机访问场景

### 9.3 自定义内存跟踪

```cpp
class MemoryTracker {
private:
    struct Allocation {
        void* ptr;
        size_t size;
        const char* file;
        int line;
    };

    std::unordered_map<void*, Allocation> allocations_;
    std::mutex mutex_;
    size_t total_allocated_ = 0;
    size_t peak_memory_ = 0;

public:
    static MemoryTracker& instance() {
        static MemoryTracker tracker;
        return tracker;
    }

    void track_alloc(void* ptr, size_t size, const char* file, int line) {
        std::lock_guard<std::mutex> lock(mutex_);
        allocations_[ptr] = {ptr, size, file, line};
        total_allocated_ += size;
        peak_memory_ = std::max(peak_memory_, total_allocated_);
    }

    void track_free(void* ptr) {
        std::lock_guard<std::mutex> lock(mutex_);
        auto it = allocations_.find(ptr);
        if (it != allocations_.end()) {
            total_allocated_ -= it->second.size;
            allocations_.erase(it);
        }
    }

    void report() {
        std::lock_guard<std::mutex> lock(mutex_);
        std::cout << "Peak memory: " << peak_memory_ << " bytes\n";
        std::cout << "Current allocations: " << allocations_.size() << "\n";

        // 按大小排序
        std::vector<Allocation> sorted;
        for (auto& kv : allocations_) {
            sorted.push_back(kv.second);
        }
        std::sort(sorted.begin(), sorted.end(),
                  [](const Allocation& a, const Allocation& b) {
                      return a.size > b.size;
                  });

        // 打印前10个最大分配
        for (size_t i = 0; i < std::min(sorted.size(), size_t(10)); i++) {
            std::cout << sorted[i].size << " bytes at "
                      << sorted[i].file << ":" << sorted[i].line << "\n";
        }
    }
};

// 重载全局new/delete
void* operator new(size_t size, const char* file, int line) {
    void* ptr = malloc(size);
    MemoryTracker::instance().track_alloc(ptr, size, file, line);
    return ptr;
}

void operator delete(void* ptr) noexcept {
    MemoryTracker::instance().track_free(ptr);
    free(ptr);
}

// 宏定义
#define NEW new(__FILE__, __LINE__)

// 使用
int main() {
    int* arr = NEW int[1000];
    // ...
    delete[] arr;

    MemoryTracker::instance().report();
}
```

### 10.1 分配器选择指南

| 场景 | 推荐分配器 | 性能提升 |
|------|-----------|---------|
| 请求处理（临时对象多） | Arena | 10-100x |

| 大内存随机访问 | Huge Pages | 1.1-1.3x |

### 10.3 常见陷阱

#### ❌ 不要：
```cpp
// 1. 频繁小对象分配
for (int i = 0; i < 1000000; i++) {
    auto* obj = new SmallObject;  // 极慢
    process(obj);
    delete obj;
}

// 2. 混用不同分配器
void* ptr = arena.allocate(100);
free(ptr);  // 错误！arena不应该free

// 3. Arena泄漏
void leak_arena() {
    Arena arena(1024);
    arena.allocate(100);
    // 忘记reset或者arena析构
}
```

#### ✅ 要：
```cpp
// 1. 使用对象池
ObjectPool<SmallObject, 1000> pool;
for (int i = 0; i < 1000000; i++) {
    auto* obj = pool.construct();
    process(obj);
    pool.destroy(obj);
}

// 2. 一致的分配/释放
void* ptr = arena.allocate(100);
// 不需要单独释放，arena.reset()批量释放

// 3. RAII管理Arena
{
    Arena arena(1024);
    // 使用arena...
}  // 自动析构释放
```
